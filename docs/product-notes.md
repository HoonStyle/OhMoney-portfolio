# 제품 설계 노트

[README](../README.md) · [구현 참고 문서](implementation-reference.md)

원격 README에 추가된 제품 방향·데모 설명을 보존한 문서입니다. 아래 내용은 설계 의도와 검증 계획이며 수익·비용·품질 효과를 입증한 측정 결과가 아닙니다.

## 타깃과 가설

초기 타깃은 금융·보험·투자 정보가 필요하지만 학습 시간이 부족한 30대 남성 1인 가구입니다. 좁은 타깃으로 메시지 톤과 상품 매칭을 정리하고, 검증 후 인접 페르소나로 확장하는 방향을 잡았습니다.

- 도메인 특화 제작 파이프라인을 자동화하면 1인 운영의 채널·토픽 확장에 도움이 될 것이라는 가설
- 도메인 프롬프트와 토픽 스코어링에 집중하고 스크립트·렌더링·게시·분석을 자동화하는 구성
- 영상 → 랜딩 → 상품 퍼널로 광고수익 외 퍼포먼스 기반 수익 모델을 검증하는 계획

## 검증 지표

| 단계 | 관찰할 지표 |
| --- | --- |
| 운영 가능성 | 일 자동 발행 편수, 하루 사람 개입 시간 |
| 콘텐츠 품질 | 평균 시청 지속율, 좋아요율, 구독 전환율 |
| 비즈니스 | 영상→랜딩 CTR, CPA, LTV |

## 선택과 대안

| 선택 | 검토한 대안 | 판단 근거 |
| --- | --- | --- |
| 좁은 초기 페르소나 | 30~40대 전체·성별 무관 | 메시지와 상품 매칭의 일관성 |
| Shorts 중심 | 롱폼·블로그 | 짧은 시청 시간, 시리즈로 정보 분산 |
| 자동 생성 + 샘플 검수 | 전부 수동 또는 완전 무인 | 1인 운영과 콘텐츠 검토의 균형 |
| 금융·보험·투자에 집중 | 다수 도메인 동시 진입 | 용어·법규·프롬프트의 도메인 맥락 활용 |
| 등급별 모델 배정 | 단일 모델 일괄 사용 | 기대수익과 비용·품질을 고려한 자원 배정 |
| 영상→랜딩→제휴상품 | 광고수익만 사용 | 클릭·전환 기반 수익화 가설 검증 |
| Mac mini 단일 노드 | 클라우드 배포 | 초기 운영 환경에 맞춘 구성; 컨테이너 사용 |
| 토픽 후보·게시 전 사람 확인 | 무인 또는 전 단계 수동 검수 | 민감 정보·규정 관련 위험 검토. 위험 제거를 보장하지 않음 |
